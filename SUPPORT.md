# Getting help

| I want to… | Go here |
|---|---|
| Set sidecar up or fix something that doesn't work | [Troubleshooting in the README](README.md#-troubleshooting) |
| Ask a question or share how I use it | [Discussions](https://github.com/flavioabbinante/sidecar/discussions) |
| Report a bug | [Bug report](https://github.com/flavioabbinante/sidecar/issues/new?template=bug_report.yml) |
| Tell you what happened on my TV | [Device report](https://github.com/flavioabbinante/sidecar/issues/new?template=device_report.yml) |
| Suggest a feature | [Feature request](https://github.com/flavioabbinante/sidecar/issues/new?template=feature_request.yml) |
| Suggest a blocklist entry | [Blocklist entry](https://github.com/flavioabbinante/sidecar/issues/new?template=blocklist_entry.yml) |
| Report a vulnerability | [Privately, see SECURITY.md](SECURITY.md) |

sidecar is maintained by volunteers. Please be patient, and include your software
version, the commands you ran and the output you saw. **Never paste serial numbers, MAC
addresses, device IDs, advertising IDs or your public IP.**
